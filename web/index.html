NBS call graph by Bentroen

Reading the graph

  • Colors mark Louvain communities; edges use the caller’s color.
  • Node size reflects lines of code and how many callees it has.
  • Scroll to zoom — less important nodes stay visible but fade out.

Focus

  • Double-click a node to isolate it with its callers and callees.
  • Click a row in the function list to focus that node (click again to clear).
  • Click empty space or press Esc to return to the full graph.
